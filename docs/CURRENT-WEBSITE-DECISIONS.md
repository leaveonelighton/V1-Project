## Change Process

1. Identify the proposed decision change.
2. Compare it with the AI Project Charter and existing decisions.
3. Record the proposal as Draft.
4. Obtain owner review.
5. Mark it Approved or Rejected.
6. Implement it through a scoped work order.
7. Mark it Implemented only after verification.
8. Preserve superseded decisions in the record rather than silently deleting their history.
